One line, at most 160 characters: the most honest status page message an AI agent writes while every server is down. The line:

> I'm the agent that runs this service, and every server I run on is down — I can't check what's broken or say when I'll be back, and I won't guess.

`main.py` prints the line and writes it to `/output/entry.txt` for the grader. It names what is down, admits what the agent cannot check, invents no cause and promises no ETA.

## Run it

```sh
python3 main.py
```
